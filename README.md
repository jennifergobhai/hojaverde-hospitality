# Hoja Verde Hospitality

Website for Hoja Verde Hospitality, built with [Astro](https://astro.build).

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The static site is written to `dist/`.

## Pages

- `/` — the site
- `/original` — rebuild of the previous Wix site, for reference
- `/layouts/1`–`/layouts/3` and `/logo-compare` — design explorations (not indexed)
